# 前端交付审查清单

- [ ] 需求与接口有来源；未知业务已让用户确认。
- [ ] 接口文档 / 需求文档 / 原型 / 截图之间的不一致已在改代码前逐条列出，用户已修订源头并指定唯一基准。
- [ ] 有设计稿：tokens 已对照项目、结构与文案一致、缺失状态已沿用或确认、逐维度对照报告有偏差原因。
- [ ] 无设计稿且全新界面：设计计划扎根产品主题，已做模板化自审；落在项目 tokens 上。已有项目：UI 样式未按本规范改造，完全沿用项目现状。
- [ ] 已核对 package.json / 锁文件中框架与主要库版本，语法与该版本官方文档一致。
- [ ] 函数单一职责、原子可测；React 组件 / hooks 为纯函数；无嵌套 reduce、递归套递归；数据结构 / 设计模式用在真实场景。
- [ ] 代码直白易读，无炫技与项目未采用的新语法。
- [ ] 命名表达业务含义；TS 无 `any` 兜底；样式只用 tokens，无魔法数、硬编码色值、`!important`。
- [ ] 提示只出现一次：接口 / 拦截器已提示则前端不追加；接口无提示则前端按语义补充。
- [ ] 重复样式已提取为变量 / mixin / 继承或公共文件；插件为 class 单例；Vue template 单根节点。
- [ ] 二次封装组件透传 attrs、class / style、事件、具名与作用域插槽，并按需 expose。
- [ ] API 层只发请求，无字段映射 / 参数拼装 / 格式化；转换在调用方 hooks 或纯函数。
- [ ] 跨端项目：目标平台已列出；CSS 用 rpx（换算基准已记录）；每个 uni.xx / Taro.xx 已查官方文档与平台兼容表；无 window / document / DOM；平台专有代码在条件编译内；App Android 权限、返回键、安全区已处理，真机验证状态已分端报告。
- [ ] 语义标签、可读名称、label 关联、键盘可达、焦点可见、reduced-motion。
- [ ] 每条 import/export 与模块变量、函数、回调、computed、props/emits 有中文注释。
- [ ] 模板关键区域和组件挂载点有中文职责说明。
- [ ] 不用三元简写业务逻辑；没有跨字段 || / ?? 候补取值。
- [ ] 实体 ID/string[] 全链路不转数字；后端不安全数值 ID 已指出阻塞。
- [ ] 当前对接动作 mock 已清理，测试桩与生产数据分离。
- [ ] 确定的后端字段原名直绑，必要转换有依据且范围小。
- [ ] 每个维护文件 ≤500 行；拆分未破坏 imports/props/events。
- [ ] 复杂浮层独立文件，重复逻辑 hooks 化；无万能 CRUD 函数。
- [ ] 已有项目按既有规范书写；新目录结构与相邻页面一致；复用项目已有组件、第三方组件、hooks、插件、指令与工具，未另起一套。
- [ ] 先读取 package.json 与注册入口，不写死组件库；新增依赖已获确认。
- [ ] 已核实组件库版本、插槽/事件/属性、项目现有封装。
- [ ] loading/失败/取消/竞态/重复操作/提示只一次；uni-app 除长连接外每个请求都有 loading 并必定关闭。
- [ ] 空值：仅 `0` 显示 `0`；null / 空串 / 缺字段的文本显示 `-`，组件显示 placeholder；未用 `value || '-'`。
- [ ] 表格、卡片、页面模块无数据显示空状态，加载中 / 失败 / 空三态分开。
- [ ] 标签不可点击且外观与按钮明显区分。
- [ ] 超出内容有明显滚动条；Tab 页签固定，滚动条在内容区域。
- [ ] 权限、主题、i18n 沿用项目，无猜测资源码。
- [ ] 项目实际配置的 lint / 格式化 / 类型检查错误与警告清零，未用禁用注释规避；目标测试 / 适用构建通过。
- [ ] 浏览器仅明确授权时使用，静态与隔离验证不冒充真实页。
- [ ] 不覆盖用户改动、不改无关模块、不擅自提交。
