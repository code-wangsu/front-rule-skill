# 设计稿还原

目标是忠实复现设计输入，而不是“做一个差不多的页面”。设计稿是视觉真源，项目 tokens 与组件是实现真源；二者冲突时列出差异让用户决定，不自行折中。

## 输入盘点与可信度

| 输入 | 可测量内容 | 处理方式 |
| --- | --- | --- |
| Figma / Sketch / 设计系统源文件 | 精确尺寸、颜色、字体、间距、组件变体 | 读标注直接使用，记录为“测量” |
| 高保真截图 / 导出图 | 比例、相对位置、颜色近似值 | 以已知参照物（基准字号、按钮高度、容器宽）推算，记录为“推算 ±n px”并说明 |
| 低保真原型 / 线框 | 结构、顺序、信息层级 | 结构按原型，视觉沿用项目既有语言，缺失处确认 |
| 现有页面 / 竞品截图 | 可对齐的现成实现 | 复用相同组件与 tokens；只复用明确要求的交互 |

先列出材料覆盖的页面状态（默认、空、加载、错误、选中、展开、移动端），缺失状态单独标注，不默默自补。

## 提取 tokens 并对照项目

1. 从设计输入列出：颜色（含透明度）、字体族、字号、字重、行高、字距、间距、圆角、边框、阴影、层级（z-index）、断点与栅格。
2. 在项目中找到 tokens 真源（CSS 变量、主题文件、设计系统包、Tailwind / UnoCSS 配置等），逐项匹配。
3. 命中：使用项目 token 名，不复制字面值。未命中：列出“设计值 / 最近的项目 token / 差异”，由用户决定新增 token 还是归并；不新造近似值，不在组件里写魔法数。
4. 字体与行高按设计值设置，不依赖浏览器或组件库默认值；字重不可用时说明替代方案，不以 `bold` 一刀切。
5. uni-app / Taro 项目先确认设计稿宽度，按 `rpx = 750 × 设计值 / 设计稿宽度` 换算（375 稿 ×2），记录换算基准；固定高度与 1px 线是否用 `px` 按设计意图说明。

## 结构映射

- 按视觉分区画组件树：页面 → 区块 → 组件 → 元素，先写出来再编码；每个节点标注对应的项目组件或新组件。
- 元素的数量、顺序、层级、对齐、分组与设计一致。不新增设计未给出的按钮、跳转、提示、分割线，也不删掉“看起来多余”的元素。
- 文案与设计稿逐字一致；明显占位文案（Lorem、示例名）标注待确认。i18n 项目入 key，不硬编码。
- 布局方式服从内容：等宽栅格用 grid，流式排列用 flex，固定定位仅在设计明确要求时使用；不以绝对定位硬凑位置。
- 优先复用项目组件；项目组件与设计外观不一致时不用 CSS 覆盖组件内部，而是列出差异让用户确认。

## 状态与边界补全

| 缺失项 | 默认处理 |
| --- | --- |
| hover / focus / active / disabled | 沿用项目同类组件的既有态；没有则确认 |
| loading / empty / error | 沿用项目统一占位与错误组件；没有则确认，不留空白容器 |
| 长文本、换行、截断 | 按设计容器尺寸决定截断或换行，并给出 title / tooltip 方案 |
| 零数据、极端数值、超长 ID | 验证不破坏布局；ID 保持字符串 |
| 权限不可见 / 不可用 | 沿用真实权限码与项目隐藏 / 禁用策略 |

## 响应式与资源

- 设计仅给桌面端时，按项目断点策略处理并说明；不假设固定宽度。子级 100% 高度要求祖先高度明确，flex 链路 `min-height: 0`。
- 图标用设计导出或项目图标库中的同名图标；没有时列出缺口，不用形状相近的图标替代。
- 图片 / 插画按设计尺寸与比例，声明宽高避免抖动；新字体、图标库、动效库必须经确认后再引入。

## 对照验证与报告

能运行且获授权时，用相同视口截图与设计稿并排对照；无法运行时明确说明只做了静态核对。按以下维度逐项报告：

```text
结构与文案：一致 / 偏差（原因） / 未验证
尺寸与间距：一致 / 偏差（原因） / 未验证
颜色与字体：一致 / 偏差（原因） / 未验证
状态与交互：一致 / 偏差（原因） / 未验证
响应式：一致 / 偏差（原因） / 未验证
```

偏差必须有原因（项目 token 不存在、组件能力限制、用户已确认调整），不写“基本一致”。

## 常见还原错误

- 整体用默认行高、默认字重、默认阴影、默认圆角，与设计值不符。
- 间距按 4 / 8 倍数“就近取整”而非设计值；1px 边框与分割线被忽略。
- 颜色用命名近似色或组件库主题色代替设计值；透明度丢失。
- 用近似图标替代、图标尺寸与描边不符。
- 把参考页面的交互、按钮或默认筛选搬进新页面。
- 用 `overflow: hidden` 或固定高度掩盖溢出；用绝对定位硬凑对齐。
- 用自己的审美“优化”设计：改色、换字体、加动效、重排顺序。
